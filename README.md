# AI-Based E-Commerce Product Price Prediction

## Project Overview

This project uses Artificial Intelligence and Machine Learning to predict e-commerce product prices using historical transaction data.

## Objective

The main objective is to build a Machine Learning model that predicts product prices based on e-commerce features such as product name, state and payment information.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Random Forest Regression
- Jupyter Notebook

## Machine Learning Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Selection
5. Categorical Encoding
6. Train-Test Split
7. Random Forest Regression
8. Price Prediction
9. Model Evaluation

## Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Project Files

- `AI_ECommerce_Product_Price_Prediction.ipynb` — Complete Jupyter Notebook

## Conclusion

This project demonstrates how Machine Learning can be applied to e-commerce data to support data-driven product pricing decisions.
